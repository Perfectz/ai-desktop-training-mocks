## ChatGPT desktop, Work, and Codex

OpenAI's new desktop design combines Chat and Work under ChatGPT, keeps Codex as a separate top-level surface, uses a ChatGPT/Codex switcher, provides a centered Chat/Work toggle, combines Chat and Work in Recents, and retains Projects. The Work landing state uses the current “What would you like to work on?” treatment, “Do anything” composer, reasoning control, and connected-app rows shown in first-party product imagery. Codex history remains separate. The mock represents those documented structures with simulated data and task progress.

## Claude Desktop

Anthropic's current experience unifies quick chats and longer Cowork-style tasks in Claude, uses one Recents list, retains Projects and a Code tab, moves Research into the add menu, offers Manual and Auto permission modes, and shows task files beside the conversation. The composer’s Output chooser stages Design, Slides, Docs, and Artifact paths. Artifacts open beside the conversation and support preview/code views, versions, copy, download, and sharing controls. The mock stages those documented patterns without invoking Claude.

## Expected differences from the real products

- Features can be plan-, platform-, geography-, and administrator-dependent.
- Vendors can stage visual and behavioral rollouts over time.
- Model names, labels, icons, keyboard shortcuts, and sidebar items can change.
- These mocks use deterministic progress rather than network or model output.
- Voice, file selection, sharing, downloads, and approvals are simulated.
- The layouts prioritize legibility and reproducibility for tutorial capture.
